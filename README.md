# 🗡️ Dungeon Explorer

A light, fast-paced 2D action game made with pure HTML5, CSS3, and JavaScript! Explore four dangerous elemental regions, fight monsters, and level up your high score—all inside your web browser.

---

## 🌟 Key Features

* 🎮 **Built-in Touch Controls:** On-screen D-Pad and action buttons optimized for iOS, iPadOS, and Android.
* ⌨️ **Keyboard Navigation:** Play on desktop using `W A S D` or standard `Arrow Keys`.
* 🗺️ **4 Unique Elemental Regions:**
  * 🔥 **Volcano:** Scorching heat and high hazards.
  * ❄️ **Frost:** Slippery paths and icy caverns.
  * ☣️ **Swamp:** Poison mist and tricky terrain.
  * 💀 **Crypt:** Dark, shadow-filled dungeons.
* ⚡ **Zero Dependencies:** No external frameworks, heavy engines, or libraries needed!

---

## 🚀 How to Play

1. Open `index.html` in any web browser.
2. **On Mobile/Tablet:** Use the on-screen D-Pad to move, tap **ATK** to attack, and **USE** to switch environments.
3. **On PC:** 
   * **Movement:** Use `W, A, S, D` or `Arrow Keys`.
   * **Actions:** Tap the screen buttons or use mouse clicks.
